# hooks

Esta carpeta contiene los custom hooks, funciones que encapsulan lógica reutilizable con estado o efectos de React.
Aquí van hooks como `useFetch`, `useLocalStorage`, `useDebounce` o `useFavoritos`.
Su nombre siempre empieza por `use` y pueden usar otros hooks como `useState` o `useEffect`.
Sirven para mantener los componentes limpios, separando la lógica de la interfaz.
