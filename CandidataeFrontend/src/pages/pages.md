# pages

Esta carpeta contiene las páginas de la aplicación, normalmente una por cada ruta (Inicio, Detalle, Favoritos, NotFound...).
Cada página compone componentes de `components/` y usa hooks y servicios para obtener y mostrar datos.
Son el punto de entrada de cada ruta, así que pueden contener lógica específica de esa vista.
Se enlazan con su URL en la carpeta `routes/`.
