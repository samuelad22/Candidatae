# layout

Esta carpeta contiene los componentes que definen la estructura general de la aplicación y se repiten en varias páginas.
Aquí van elementos como el Header, Footer, Sidebar, Navbar o el contenedor principal (`MainLayout`).
Su función es organizar el espacio y la navegación, no mostrar contenido específico de una página.
Normalmente envuelven a las páginas mediante `children` o `<Outlet />` de react-router.
