# common

Esta carpeta contiene los componentes genéricos y reutilizables de la aplicación, que no dependen de ninguna página ni funcionalidad concreta.
Aquí van elementos de interfaz básicos como botones, modales, inputs, loaders o tarjetas.
Deben recibir todo por `props` y no contener lógica de negocio ni llamadas a APIs.
Si un componente se usa en más de una página, probablemente pertenece aquí
